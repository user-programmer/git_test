Part 1 — ANN Fundamentals

How a network of artificial neurons learns to make decisions, with a concrete example using real numbers.

1. What is an Artificial Neural Network?

Biological Neuron

  • Receives signals through dendrites
  • Cell body sums up all signals
  • If sum exceeds threshold → fires through axon
  • Connects to next neuron via synapse

Artificial Neuron

  • Receives numeric inputs (x₁, x₂, …)
  • Each input has a weight (w₁, w₂, …)
  • Sums weighted inputs + bias
  • Passes through activation function → output
🧠
An ANN is a collection of layers of neurons, where each layer transforms its inputs and passes the result forward. By adjusting the weights through training, the network learns to recognize patterns.

4. Activation Functions

⚡
Without activation functions, stacking layers would just be linear algebra — the whole network collapses into a single linear equation. Activation functions introduce non-linearity, enabling the network to learn complex patterns.

Sigmoid σ(z)

σ(z) = 1 / (1 + e⁻ᶻ)

Output range: 0 to 1

Good for Binary output (probability)

Weakness Vanishing gradient on very large/small z

Example: z=0 → 0.5  |  z=2 → 0.88  |  z=-2 → 0.12

ReLU — Rectified Linear Unit

ReLU(z) = max(0, z)

Output range: 0 to +∞

Good for Hidden layers — fast, avoids vanishing gradient

Weakness Dead neuron if z always ≤ 0

Example: z=3.5 → 3.5  |  z=-1.2 → 0

Tanh — Hyperbolic Tangent

tanh(z) = (eᶻ - e⁻ᶻ) / (eᶻ + e⁻ᶻ)

Output range: -1 to +1

Good for Zero-centered, better than sigmoid for hidden layers

Example: z=0 → 0  |  z=1 → 0.76  |  z=-1 → -0.76

Softmax

softmax(zᵢ) = eᶻⁱ / Σ eᶻʲ

Output range: 0 to 1, sums to 1

Good for Multi-class output — converts scores to probabilities

Example: [2.0, 1.0, 0.1] → [0.70, 0.24, 0.06]

W₂ = [0.7, 0.3, -0.5]

Step 1 — Hidden Layer (Weighted Sum)

h₁_z = (0.8×0.5) + (0.7×-0.3) + 0.1 = 0.40 - 0.21 + 0.10 = 0.29
h₂_z = (0.8×0.4) + (0.7×0.6) + (-0.1) = 0.32 + 0.42 - 0.10 = 0.64
h₃_z = (0.8×-0.2) + (0.7×0.8) + 0.2 = -0.16 + 0.56 + 0.20 = 0.60

Step 2 — Apply Sigmoid Activation to Hidden Layer

h₁ = sigmoid(0.29) = 0.572
h₂ = sigmoid(0.64) = 0.655
h₃ = sigmoid(0.60) = 0.646

Step 3 — Output Layer (Weighted Sum)

out_z = (0.572×0.7) + (0.655×0.3) + (0.646×-0.5) + 0.05
= 0.400 + 0.197 - 0.323 + 0.050
= 0.324

6. Loss Function & Backpropagation

Loss Function

Measures how wrong the prediction is. The goal of training is to minimize loss.

Binary Cross-Entropy:
L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]

If real y=1 (Pass) and ŷ=0.58:
L = -[1×log(0.58) + 0×log(0.42)] = -log(0.58) = 0.544

If ŷ were 0.99 (very confident, correct):
L = -log(0.99) = 0.01 (low loss ✓)

Multi-class classificationCategorical Cross-Entropy

Backpropagation — How the Network Learns

🔄
Backpropagation uses the chain rule of calculus to compute how much each weight contributed to the error. It then adjusts weights to reduce the loss — moving a small step in the direction of lower error.
1
Forward Pass — compute prediction ŷ through all layers.
2
Compute Loss — measure how wrong ŷ is compared to true label y.
3
Compute Gradients — starting from output layer, work backwards. For each weight w: ∂L/∂w = how much does loss change if w changes slightly?
4
Update Weights — nudge each weight in the direction that reduces loss: w = w - learning_rate × ∂L/∂w
Weight update rule (Gradient Descent):
w_new = w_old - η × (∂Loss / ∂w)

Example: w=0.7, gradient=0.12, learning_rate η=0.1
w_new = 0.7 - 0.1 × 0.12 = 0.7 - 0.012 = 0.688
Intuition: If increasing w makes the loss go up (positive gradient), we decrease w. If increasing w makes loss go down (negative gradient), we increase w. The learning rate η controls how big each step is.

Part 1 Summary

  • An ANN is made of layers of neurons. Each neuron computes a weighted sum then applies an activation function.
  • Forward pass: input flows through layers to produce a prediction.
  • Loss measures the error. Backpropagation computes gradients. Gradient descent updates weights.
  • After many epochs, the network learns weights that make accurate predictions.

Part 2 — Grayscale Image Processing

How a pure ANN handles a single-channel (grayscale) image — every pixel becomes an input neuron.

8. What is a Grayscale Image?

Single Channel

  • Each pixel = one number (0–255)
  • 0 = pure black
  • 255 = pure white
  • 128 = mid-grey
  • No color information — just brightness
  • File size: smaller than RGB (1× the data)

Why Use Grayscale First?

  • Simpler: 1 channel instead of 3
  • Fewer inputs to the ANN → easier to understand
  • Enough for many tasks: digit recognition, edge detection
  • Famous MNIST dataset uses 28×28 grayscale images

11. Hidden Layer Processing — What Neurons Learn

💡
During training, each neuron in the hidden layer learns to detect a specific pattern in the pixel values. With enough neurons and epochs, the network learns which pixel combinations indicate "Dark", "Medium", or "Bright".

Hidden Neuron A

Learns to detect high values in left columns (pixels 0–31). High weight on left pixels, negative weight on right pixels.

z_A = Σ(left_pixels × large_weights) + Σ(right_pixels × neg_weights)

Hidden Neuron B

Learns to detect average brightness across all 64 pixels. Roughly equal weights on all inputs.

z_B = Σ(all_pixels × ~equal_weights)

Hidden Neuron C

Learns to detect high values in right columns (pixels 32–63). High weight on right pixels.

z_C = Σ(right_pixels × large_weights)

Layer 1 → Layer 2 → Output (Abbreviated)

Input: 64 pixel values (normalized 0–1) [0.08, 0.12, 0.16, ..., 0.55, 0.63, 0.79, 0.96]

After Layer 1 (ReLU): 32 neuron activations
[0.0, 0.32, 0.0, 0.71, 0.15, 0.0, 0.88, 0.0, 0.42, ...] ← many zeros (ReLU kills negatives)

After Layer 2 (ReLU): 16 neuron activations
[0.55, 0.0, 0.72, 0.0, 0.34, 0.81, ...]

Output scores (before softmax): [1.2, 0.3, 3.7]
After Softmax: [0.07, 0.03, 0.90]
Prediction: Class 2 = BRIGHT ✓

Part 2 Summary

  • Grayscale: 1 channel, each pixel = 1 number (0–255).
  • Flatten: 2D grid → 1D vector. 8×8 → 64 inputs. MNIST 28×28 → 784 inputs.

  • ANN processes these 64 numbers through fully connected layers, outputs class probabilities via Softmax.
  • It works but loses all spatial information — that's why CNNs are better for images.

13. What is an RGB Image?

🎨
RGB = Red, Green, Blue. Every pixel in a color image has three values — one for each color channel — each ranging from 0 to 255. Together they mix to produce the pixel's color.

Red Channel

Controls how much red light. 0 = no red, 255 = maximum red. Stored as a separate 2D matrix.

Blue Channel

Controls how much blue light. 0 = no blue, 255 = maximum blue. Same spatial size as red & green.

Key Insight: ANN Treats All Channels Equally

In a pure ANN, all 192 values (R₁…R₆₄, G₁…G₆₄, B₁…B₆₄) enter as a flat list. The network doesn't "know" which values come from which channel — it just learns weights. But since red pixels will have consistently high values in positions 1–64 and low in 65–192 for a red scene, the network infers the channel structure from the patterns in data over many training examples.

17. Why CNN Beats ANN for Images

🔍
A pure ANN works on images but has fundamental limitations. Convolutional Neural Networks (CNN) were specifically designed to fix those limitations using the spatial structure of images.

ANN Problems with Images

  • Problem No spatial awareness: pixel at (0,0) has no connection to its neighbor at (0,1) in the learned structure
  • Problem Not translation-invariant: a cat at top-left ≠ cat at bottom-right (different input positions!)
  • Problem Too many parameters: 224×224×3 = 150K inputs → first hidden layer alone has millions of weights
  • Problem No weight sharing: every spatial location uses completely different weights

How CNN Solves Each Problem

  • Solution Convolution: filters slide over the 2D image, preserving spatial relationships between neighboring pixels
  • Solution Weight sharing: same filter scans whole image — a cat detector works anywhere in the image
  • Solution Pooling: reduces spatial size, building translation invariance
  • Solution Far fewer parameters: a 3×3 filter = 9 weights (used everywhere!) vs millions for ANN

Parameter Count Comparison

ModelInput SizeFirst Layer WeightsTotal Parameters
ANN28×28 grayscale784 × 512 = 401,408~500K

When to Use Each

Use ANN when...

  • Tabular / structured data
  • Small images (<32×32)
  • Features don't have spatial meaning
  • Quick baseline needed
  • Example: predict price, classify iris flower

Use CNN when...

  • Images (any size)
  • Spatial structure matters
  • Translation invariance needed
  • Object detection / segmentation
  • Example: detect cats, classify X-rays

ANN + CNN Hybrid

  • CNN extracts image features
  • ANN (fully-connected) classifies
  • This is how YOLOv8, ResNet, VGG all work
  • The ANN head is the final layers of every CNN!

Final Summary — ANN on Images

Grayscale (Single Channel)

  • 1 value per pixel (0–255)
  • Flatten H×W → 1D vector
  • N inputs = H × W
  • Good for: digits, shapes, edges
  • Loses color, but keeps brightness

RGB (Multi-Channel)

  • 3 values per pixel (R, G, B each 0–255)
  • Flatten H×W×3 → 1D vector
  • N inputs = H × W × 3
  • Good for: color-sensitive tasks
  • Keeps color but 3× more parameters

The Key Limitation of Pure ANN on Images

Flattening destroys the 2D spatial structure. Neighboring pixels lose their "neighbor" relationship in the flat vector. CNNs solve this by processing with sliding filters that preserve spatial context — which is why CNNs dominate all image tasks today. However, ANN principles (weights, biases, activations, forward pass, backpropagation) are the foundation of every CNN. A CNN's final classification layers ARE a small ANN. You now understand both.
