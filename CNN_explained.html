ReLU Activation

Rectified Linear Unit — removes noise, keeps signal

Formula: max(0, x)

InputOutputWhy
-50negative → killed
-10negative → killed
00zero → stays

Why ReLU is needed

Without ReLU
Only straight line learning — cannot detect curves like elephant trunk or snake coil
With ReLU
Can learn complex, non-linear patterns — any animal shape or texture
💡
Simple: ReLU kills noise (negatives) and keeps useful signal (positives). Applied after every Conv layer.

Loss Function

Cross-Entropy Loss — measures how wrong the prediction was

Good prediction — Low Loss

True label (elephant): [1, 0, 0, 0, 0 ] CNN predicted: [0.82, 0.10, 0.02, 0.04, 0.02] Loss = -(1 × log(0.82)) = -(1 × -0.096) = 0.096 ✓ Small loss!

Wrong prediction — High Loss

True label (elephant): [1, 0, 0, 0, 0 ] CNN predicted: [0.05, 0.80, 0.05, 0.05, 0.05] Loss = -(1 × log(0.05)) = -(1 × -2.99) = 2.99 ✗ Large loss!
Goal of training: Minimise this loss value across all 700 training images — pushing it as close to 0 as possible.

Backpropagation

How CNN adjusts its weights after each mistake

Forward vs Backward Pass

→ Forward Pass
Image flows through CNN → prediction → calculate loss
← Backward Pass
Loss flows backwards through each layer → find how much each weight contributed to the error → adjust weights

Weight Update Formula

new_weight = old_weight − (learning_rate × gradient)
Learning Rate
Usually 0.001
Controls step size
Gradient
Direction & amount to change the weight
Example
0.5 − (0.001 × 0.3)
= 0.4997
💡
Think of it as: CNN made a mistake → it adjusts every weight slightly so it does a little better next time. Repeated thousands of times = a well-trained model.

Complete Flow Summary

Everything from raw image to final prediction

📷 1000 Animal Images (50×50×3)
Elephant, Lion, Snake, Crocodile, Hippos
⚙️ Preprocessing
Normalise (÷255) + One-Hot Encoding + 70/15/15 split
🔍 Conv Layer 1 (32 filters, 3×3)
Learns edges & textures → 50×50×3 → 48×48×32
🔍 Conv Layer 2 (64 filters) + MaxPool
Learns shapes → 46×46×64 → pooled to 23×23×64
🔍 Conv Layer 3 (128 filters) + MaxPool
Learns body parts → 21×21×128 → pooled to 10×10×128
📏 Flatten → 12,800 values
3D volume unrolled to 1D list
🧠 Dense (512 neurons) + Dropout (50%)
Combines all features, prevents memorisation
📉 Loss (Cross-Entropy) + Backpropagation
Measures error → adjusts all weights → repeat per batch
✅ Prediction: 🐘 Elephant = 82%, 🦁 Lion = 10% ...
Final accuracy on test set: 94.6%

CNN takes your animal image, breaks it into pixels, slides filters to find edges → shapes → body parts, shrinks data step by step with pooling, flattens it, combines everything in dense layers, and outputs which of your 5 animals it is — learning from mistakes through backpropagation across many epochs.
